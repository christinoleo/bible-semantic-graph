The popular Muslim explanation framing successive revelations as software versions — [[torah]] = 1.0, [[psalms]] = 2.0, [[injil]] = 3.0, [[quran]] = final — so adherence to the latest issued version is normative without requiring the prior ones to be false or corrupted, only earlier. The argument finesses [[tahrif]] (no textual corruption needed) while still grounding the Muslim's call for Jews and Christians to "upgrade." Christian apologists reply that this metaphor presupposes the very thing in dispute — that Muhammad's revelation is from the same source — and cannot answer Q 5:47's standing instruction to *judge by the Gospel*, which has no software-versioning analogue (an instruction to "judge by version 3.0" cannot legitimately point users back to version 2.0).
